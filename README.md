# Parvaz Daily — پرواز روزانه

یک نسخه‌ی وب واکنش‌گرا از طرح ارسالی، با رابط فارسی و راست‌چین.

## اجرا
1. فایل ZIP را استخراج کنید.
2. فایل `index.html` را با مرورگر باز کنید.
3. برای تجربه‌ی بهتر، از Chrome یا Edge استفاده کنید.

## فایل‌ها
- `index.html` — فایل اصلی برنامه و ساختار صفحات
- `styles.css` — استایل‌ها و طراحی واکنش‌گرا
- `app.js` — تعاملات، ثبت/حذف موارد و ذخیره‌سازی
- `README.md` — راهنمای اجرا

اطلاعات در مرورگر و روی همان دستگاه، با `localStorage` ذخیره می‌شود؛ این نسخه به سرور یا حساب کاربری وصل نیست. برای انتشار به شکل اپلیکیشن اندروید یا همگام‌سازی بین دستگاه‌ها، به مرحله‌ی جداگانه‌ای نیاز است.
